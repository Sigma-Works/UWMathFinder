# Security policy

UWMathFinder is a static site with no accounts, logins or server-side code, but
problems like script injection through a shared link still matter.

## Reporting a vulnerability

Please **don't** open a public issue. Instead, report it privately through GitHub:
**Security → Report a vulnerability** on this repository
([direct link](https://github.com/Sigma-Works/UWMathFinder/security/advisories/new)).

Include what you found, how to reproduce it (a URL is ideal), and what an attacker
could do with it. We'll reply as soon as we can and credit you in the fix if you'd like.

Only the live site (uwmathfinder.com) and the `main` branch are supported.
